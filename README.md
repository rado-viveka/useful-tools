# Useful tools

Small tools I use day to day.

| Tool | What it does |
| --- | --- |
| [markdown-preview-line-numbers](markdown-preview-line-numbers/) | VS Code extension: line numbers in the Markdown preview, and `#L<line>` links that scroll to the line. |
| [intellij-markdown-preview-line-numbers](intellij-markdown-preview-line-numbers/) | IntelliJ IDEA plugin: line numbers in the Markdown preview, and `#L<line>` links that open the file at the line. |
